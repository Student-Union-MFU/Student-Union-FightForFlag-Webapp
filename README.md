# Fight For Flag 2026

A mobile-focused web platform for **Look Mae Fah Fight for Flags and Sports Festival 2026** at Mae Fah Luang University.

The website provides event information, school voting, and an interactive interface designed around the spirit of the Fight for Flag festival.

## About

The **Look Mae Fah Fight for Flags and Sports Festival 2026** was held from **2–22 February 2026** at the **Mae Fah Luang University Sports Center**.

The event was organized through collaboration between the **Student Union** and the **Student Development Division**, continuing an important university tradition that brings students together through teamwork, competition, and school spirit.

The festival included:

- National Flag Ceremony
- Faculty Flag Assembly
- Torch Lighting Ceremony
- Cheerleading Performances
- Student Club Performances
- Cheerleading Competitions
- Musical Performances
- Sports Activities
- School Spirit Activities

The event brought together students from all **14 schools** of Mae Fah Luang University.

## Features

- Mobile-focused responsive design
- School voting system
- Voting status and countdown interface
- Fight For Flag event information
- School-focused content
- Animated vertical card marquee
- GSAP animations
- Responsive layouts for mobile and desktop
- Modern UI with Tailwind CSS
